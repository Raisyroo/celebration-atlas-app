# Celebration Atlas — Cinematic Gallery Set (Production Prompt Pack)

Use this prompt pack to generate a cohesive image set for the Celebration Atlas interactive archive.

## Global Cohesion Lock (applies to all 5 images)
- Same place and time: a Michigan county fair, same summer evening, same event window (~7:45–9:15 PM), golden-hour shifting to twilight.
- Same visual language: storybook Americana, painterly realism, natural skin texture, documentary emotion, subtle cinematic softness.
- Same color palette: warm amber, dusty rose sunset, barnwood brown, denim blue, carnival tungsten, soft firework magenta highlights.
- Same atmosphere: light summer haze, floating dust motes in warm beams, distant midway glow, community warmth.
- Same camera feel: human eye-level perspective, occasional intimate wide-angle, gentle depth falloff, no extreme distortion.
- Same realism guardrails: authentic Midwest details, imperfect candid moments, no plastic faces, no hyper-HDR, no over-saturation.

## Universal Negative Constraints (applies to all 5 images)
No text, logos, watermarks, borders, captions, UI overlays, split frames, collage composition, poster layout, comic styling, faceted geometry, surreal anatomy, duplicate limbs, artificial gloss skin, aggressive sharpening.

## 1) MAIN HERO IMAGE (4:5 portrait, target 1600×2000)

**Use case:** `photorealistic-natural`  
**Asset type:** Celebration Atlas gallery hero image  
**Primary request:**
A cinematic, emotionally dominant festival memory from a Michigan summer fair at dusk: foreground subject is a multigenerational family paused at the edge of the midway as the first fireworks bloom behind a Ferris wheel. One child in the foreground holds a lemonade cup with condensation; grandparents and parents are softly layered behind, sharing a quiet smile. Dust in the warm light catches the glow from string lights and ride bulbs.

**Scene/backdrop:**
Michigan county fair midway near livestock barns and food stands, visible ferris wheel, tree line at horizon, early fireworks beginning.

**Subject:**
Family connection and wonder in a single iconic moment.

**Style/medium:**
Painterly realism, storybook Americana, cinematic documentary still.

**Composition/framing:**
4:5 portrait; strong foreground focal subject; clear subject separation; midground family cluster; atmospheric fair background with depth.

**Lighting/mood:**
Golden-hour remnants + tungsten midway glow + first fireworks ambience; nostalgic, tender, immersive.

**Color palette:**
Warm amber, dusky peach, denim blues, muted carnival reds, soft magenta firework accents.

**Materials/textures:**
Denim, cotton, worn leather boots, wooden railings, dust particles, paper tickets, condensation on cup.

**Constraints:**
No staged posing feel; keep expressions natural and candid; preserve authentic Midwest fair details.

**Avoid:**
Overly dramatic VFX sky, neon overload, perfect CGI skin, fantasy costumes.
